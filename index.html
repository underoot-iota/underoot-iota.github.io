Software Development Engineer, App Payments

I own the bill-payments backend: the Go service behind every BBPS bill in the app, carrying 1.7M+ transactions a month. I design and ship it, and I'm on call for it and three other services on the payments path.

  • Built bill discovery over SMS, so the app finds your bills instead of asking you to type account numbers. It adds 600+ bills a day. Bringing electricity, gas, prepaid and loan billers onto it meant parsing whatever each vendor calls a plan and normalising it into one model.
  • Redesigned how billers work. A registry with capability overlays turned onboarding a biller from a change scattered across the codebase into a single file, and a CI gate keeps it that way.
  • Made the money path correct under concurrency. Postgres advisory locks and read-then-write dedupe where account creation has to serialise, optimistic checks where contention is rare. A financial write happens once or not at all.
  • Made the bill pipeline scale: indexed, time-windowed queries in place of full-table scans so batch jobs finish inside their window, and asynchronous offset commits to unblock Kafka consumer concurrency.
  • Delivered the second-network path for a zero-forex Visa credit card in card issuance: a tenant-aware CCMS client, network-aware limits and a Kafka onboarding consumer.

Agents in production

I've been building with LLMs since 2024. Two systems from that work run in production.

Mad-Eye shipped at slice

An agent that reviews every deploy

Every production release at slice is reviewed by an LLM agent. Mad-Eye pulls the metrics, the logs and the code diff for a deployment, reasons about whether the change is doing what it claimed it would, and says so in Slack.

Most of the design work went into trust boundaries rather than prompts. The agent holds production credentials and reads production logs, which is text that users, and therefore attackers, can influence. So it is explicit about what the agent may act on, what it may only report, and where an injected instruction stops.

Python · FastAPI · Temporal · Claude on AWS Bedrock · Langfuse
